# 客户档案模块 · 功能需求规格(v1)

> 面向 UI 设计与开发。参考最新设计 `.claude/mockups/index.template.html` 的「客户档案」页(列表 + 详情抽屉 + 跟进时间线),由产品方按专家判断升级。与「智能询盘」「智能报价」「产品资料库」强对接。

## 1. 定位与目标

客户档案是产品的 **记忆与数据资产**:Agent 自动建档、自动记录每一次互动、沉淀客户偏好与成交话术;并把这些**反哺**给智能询盘(老客户识别、上下文)和智能报价(复购/偏好→定价与议价)。

它不是"通讯录",而是**会自动积累、会主动提醒、能让 AI 更懂这个客户**的 360° 视图。

目标:零手工建档、跨渠道不断线、老客户复购不漏、流失早预警。

## 2. 铁律:自动沉淀,人工只做修正

- 默认 **AI 自动建档 + 自动时间线**,销售不手敲资料;人工只做纠正/补充。
- AI 背调/偏好为**辅助洞察**,关键结论(分级、风险)可解释、可人工修正,不黑箱。
- 合规优先:支持数据导出与**彻底删除(被遗忘权 / GDPR)**;租户隔离。

## 3. 智能内核(客户档案版)

1. **统一客户视图(跨渠道身份合并)**:同一买家从邮件/WhatsApp/阿里/表单来,自动合并为一个档案(邮箱/电话/公司域名),不再上下文断裂。
2. **AI 自动建档与时间线**:从询盘自动建档;每次互动(收到询盘/甄别/报价/AI 回复/护栏/成交)自动入时间线,无需手工记录。
3. **AI 背调 / enrichment**:公司背景、规模(门店数)、贸易/信用信号自动补全,形成背调摘要。
4. **客户价值与分级(区别于单条询盘等级)**:基于历史成交、累计金额、复购、赢率,给**客户级价值/分级**,并预测成交/复购可能。
5. **偏好画像**:价格敏感度、常购品类、账期偏好、关注认证、沟通语言/时区——**结构化并反哺**智能报价(定价/议价)与智能询盘(应答)。
6. **主动洞察 / 下一步建议**:今日该优先跟谁、何时跟、跟什么(话术);**流失预警** + **复购机会提醒**。
7. **可解释**:分级/风险/建议均附自然语言理由与依据,可人工修正。

## 4. 两个维度必须区分(避免混淆 —— 已决策)

| 维度 | 含义 | 颗粒度 |
| --- | --- | --- |
| **询盘等级 A/B/C** | 这条询盘有多值得跟 | 单条询盘(来自智能询盘) |
| **客户价值/分级** | 这个客户整体有多重要 | 跨历史(成交/金额/复购/赢率) |

UI 不可把两者画成同一个角标;客户档案以**客户价值**为主,单条询盘等级在"关联询盘"里各自展示。

## 5. 角色与范围
- 角色:销售(看档案、跟进)、负责人(看价值/风险/导出)、管理员(合规删除)。
- 范围内:客户的自动建档、统一视图、背调、偏好、价值分级、互动时间线、跟进建议、导出/删除。
- 范围外:会话与发送(智能询盘)、报价与底价(智能报价)、产品事实(产品资料库)。本模块**聚合**它们并回喂洞察。

## 6. 数据模型(标准字段)
- 主体:公司、联系人(可多人)、国家/地区、企业域名、渠道账号(email/whatsapp/...)。
- 价值:客户分级、累计成交数、累计金额、关联询盘数、最近活动时间、关系状态(新/报价中/谈判中/样品/已成交/老客户/流失风险)。
- 洞察:背调摘要、**偏好画像(结构化:价格敏感度/账期/品类/认证/语言/时区)**、风险信号、预测(复购/流失)。
- 记录:互动时间线(自动)、关联询盘/报价/订单、备注(人工)。
- 合规:数据来源标注、删除/匿名化状态。

## 7. 功能需求(FR)

### FR-A 统一视图与自动建档
- A1 从入站询盘自动建档;同一买家跨渠道**自动合并**(邮箱/电话/域名),支持人工合并/拆分纠错。
- A2 一个客户聚合其全部:联系人、渠道、关联询盘/报价/订单、时间线。
- A3 多联系人支持(同公司不同人)。

### FR-B 自动时间线
- B1 每次互动自动入时间线(收到询盘/甄别/产品匹配/报价/AI 回复/护栏/接管/成交/跟进)。
- B2 时间线可筛选(类型/时间),可定位到对应会话/报价。

### FR-C 背调与偏好(AI 洞察)
- C1 AI 背调摘要(公司背景/规模/信用信号),可人工修正。
- C2 **偏好画像**结构化沉淀,并**回喂**智能报价与智能询盘(议价策略、定价建议、应答口吻)。
- C3 洞察均可解释(依据 + 置信度)。

### FR-D 客户价值与分级
- D1 客户级价值/分级(历史成交/金额/复购/赢率),与单条询盘等级分开。
- D2 预测复购可能与流失风险。

### FR-E 主动跟进与提醒
- E1 **下一步建议 / next-best-action**:今日优先跟进名单 + 时机 + 话术建议。
- E2 **流失预警**(久未互动/停滞);**复购机会**(老客户周期性提醒)。
- E3 建议可一键转为跟进任务/进入会话。

### FR-F 检索与运营
- F1 列表:分级/价值、关系状态、关联询盘、成交、累计金额、最近活动;筛选(状态/分级/区域/风险);搜索。
- F2 导出 CRM(受权限/合规约束)。

### FR-G 合规与留痕
- G1 数据**导出**与**彻底删除/匿名化**(被遗忘权);删除留痕。
- G2 所有自动建档/修改/合并/删除可审计;租户隔离。

## 8. 给 UI 的视图清单
1. **客户列表**:表格(客户/分级·价值/关系状态/关联询盘/成交/累计金额/最近活动)+ 筛选 + 搜索 + 导出。
2. **客户档案(抽屉/详情)**:头部(公司/联系人/客户价值)、统计卡(关联询盘/历史成交/累计金额)、**背调摘要**、**偏好画像**、**AI 下一步建议**、关联询盘/报价/成交、**自动时间线**、合规(导出/删除)。
3. **跨渠道合并/拆分**确认。
4. **流失/复购提醒**视图或列表入口。
5. 空/加载/错误态。

## 9. 边界与异常
- 客户价值 ≠ 询盘等级,UI 与逻辑都分开。
- 合并需谨慎:低置信合并给人工确认,可拆分回退。
- 背调/偏好为洞察,关键决策可人工改写,不黑箱。
- 删除为彻底删除/匿名化,且联动相关引用处理。

## 10. 分期(MVP / P2)
**MVP(路演必须)**:统一客户视图(自动建档 + 自动时间线)、背调摘要、客户价值/分级(与询盘等级分开)、列表/详情/筛选/导出、基础跨渠道合并(邮箱/电话)、合规删除。
**P2**:偏好画像结构化回喂、next-best-action / 流失预警 / 复购提醒、enrichment 自动化、高级身份解析(模糊合并)、预测模型。

> MVP 的"智能"至少落在:**跨渠道自动合并 + 自动时间线 + 背调摘要 + 客户价值分级**——这是比"通讯录 + 手工备注"更进一步的最小可演示智能。

## 11. 验收标准(抽样)
- 同一买家先邮件后 WhatsApp 进来 → 合并到一个档案,时间线含两条来源。
- 新询盘 → 自动建档,无需手工录入,背调摘要自动生成。
- 老客户久未互动 → 出现流失预警 / 复购提醒(P2)。
- 删除某客户 → 彻底删除/匿名化并留痕。
- 客户档案的"客户价值"与其名下单条询盘的 A/B/C 分别展示,不混。

## 12. 依赖
智能询盘(老客户路由、会话上下文、跨渠道入站)· 智能报价(复购/偏好→定价与议价;成交回写)· 产品资料库(客户购买/关注的产品)· 后端 `app/services/crm`、`/api/v1/customers`(含 GDPR 删除)、身份合并逻辑。
