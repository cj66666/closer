# 产品资料库模块 · 功能需求规格(v1)

> 面向 UI 设计与开发。参考最新设计 `.claude/mockups/index.template.html` 的「产品库」页(卡片/列表 + 搜索 + Excel 批量导入 + 新增),由产品方按专家判断升级。与「智能报价」「智能询盘」强对接。

## 1. 定位与目标

产品资料库是产品的 **知识底座**:智能询盘的产品匹配、需求理解,智能报价的成本/规格、报价/PI 的 grounding,全部以它为单一事实源。

它不是"产品表格",而是**让 AI 看得懂、报得准、答得专业的结构化知识库**。

目标:录入快、字段全、匹配准、口径一致;让"可被 AI 自动报价/应答的产品"占比最大化。

## 2. 铁律:产品库管"事实",不管"价格"

- 产品库只到 **成本(产品事实)** 为止;毛利/阶梯/底价等**定价决策全归智能报价**(见 [smart-quoting-requirements.md](smart-quoting-requirements.md) 第 11 节)。
- AI 可**辅助抽取/归一/增强**,但产品事实(尤其**成本**)需**人工确认**才入库,绝不静默写入或编造。

## 3. 智能内核(产品库版)

1. **AI 辅助录入**:上传 Excel/CSV/规格表 PDF / 产品图 / 贴一段描述 / 贴产品 URL → AI 抽取成结构化字段,人工确认入库。把"录入"从手敲变成"确认"。
2. **智能列映射**:批量导入时自动识别中英文列名别名(name/产品名、cost/成本、moq/起订量…),自动对齐到标准字段。
3. **去重与冲突检测**:同 SKU/高相似产品自动识别,提示合并或区分。
4. **完整度 + 报价就绪检测**:缺成本/MOQ/规格/定价规则的产品自动标记"不可自动报价",并指出缺什么。
5. **检索增强(RAG)**:为每个产品自动生成检索关键词/别名/embedding,提升智能询盘的产品匹配命中(尤其非标、外文询盘)。
6. **结构化规格与认证**:规格、认证、质保结构化,供 PI grounding 与匹配差异提示。

## 4. 角色与范围
- 角色:产品/售前(维护产品事实)、运营(批量上下架)。
- 范围内:产品的录入(单条/批量/AI 辅助)、维护、检索、结构化、完整度/就绪状态、匹配知识。
- 范围外:定价/底价(智能报价)、客户(客户档案)、渠道(渠道接入)。

## 5. 数据模型(标准字段)

- 标识:SKU(唯一键)、名称、品类。
- 商务:**成本**、币种、MOQ、交期(lead time)、质保、库存/状态(在售/停产/现货/备货)。
- 规格:结构化 specs(材质、尺寸、规格参数…)、认证(CE/FDA…)、包装、重量/体积(供物流/landed cost)、HS code(可选)。
- 媒体:图片、产品描述、附件(规格表/说明书)。
- 匹配:检索关键词/别名(可 AI 生成)、embedding(P2)。
- 派生(只读展示):报价就绪状态、完整度评分。

## 6. 功能需求(FR)

### FR-A 产品录入(上传产品 —— 用户明确要求)
- A1 **单条新增**:表单录入全部字段(含规格/认证的结构化输入)。
- A2 **批量导入**:Excel/CSV 上传 → **AI 智能列映射** → 校验(必填/格式/重复)→ **预览 + 行内纠错** → 确认入库;提供**模板下载**;导入结果含成功/失败/重复明细。
- A3 **AI 辅助录入(智能亮点,P2 起)**:上传规格表 PDF / 产品图 / 粘贴描述 / 贴产品 URL → AI 抽取字段 → 人工确认入库。
- A4 录入/导入均做**去重与冲突检测**(同 SKU/相似品),提示合并或新建。
- A5 成本等敏感字段 AI 抽取后**必须人工确认**,不默认采纳。

### FR-B 维护与组织
- B1 编辑/上下架/停产(状态流转);软删除可恢复。
- B2 品类管理;批量操作(批量改品类/状态/导出)。
- B3 变更留痕(尤其成本变更,联动智能报价预警)。

### FR-C 检索与浏览
- C1 卡片/列表双视图(参考现设计),搜索(名称/SKU/品类),筛选(品类/库存/报价就绪/完整度)。
- C2 列表项展示:SKU、名称、品类、成本、MOQ、库存、**报价就绪徽标**。

### FR-D 完整度与报价就绪
- D1 每个产品计算**完整度评分**与**报价就绪状态**(成本 + MOQ + 定价规则齐全 = 就绪)。
- D2 未就绪产品醒目标记并指出缺项;提供"去配置定价"跳转智能报价。
- D3 仪表:就绪产品占比(目标最大化)。

### FR-E 匹配知识(支撑智能询盘)
- E1 维护/自动生成检索关键词与别名,提升产品匹配命中。
- E2 规格/认证结构化,支持匹配差异提示(低置信度返回备选品 + 差异)。
- E3 embedding 语义检索(P2)。

### FR-F 留痕与隔离
- F1 录入/编辑/导入/删除留痕可审计;租户隔离。

## 7. 给 UI 的视图清单
1. **产品列表**:卡片/列表切换、搜索/筛选、库存 + **报价就绪**徽标、批量操作。
2. **产品详情/编辑**:结构化规格与认证、图片、成本、状态、报价就绪提示(去配置定价)。
3. **新增产品表单**(单条)。
4. **批量导入向导**:上传 → AI 列映射(可人工调整)→ 校验预览(行内纠错、重复标记)→ 入库结果;模板下载入口。
5. **AI 辅助录入**(P2):上传 PDF/图/URL/文本 → 抽取结果待确认 → 入库。
6. **去重/冲突**确认弹窗。
7. 空/加载/错误态。

## 8. 边界与异常
- 产品库不含价格;价格在智能报价。
- AI 抽取/映射结果一律可人工修正;成本必须人工确认。
- 导入部分失败 → 成功的入库、失败的给原因可重试,不整批回滚(除非用户选择)。
- 停产产品在智能报价中不可报价(报价闸门)。

## 9. 分期(MVP / P2)
**MVP(路演必须)**:单条新增 + Excel/CSV 批量导入(AI 列映射 + 校验预览 + 模板)+ 列表/详情/编辑 + **报价就绪状态** + 基础匹配关键词。
**P2**:AI 辅助录入(PDF/图/URL/文本)、embedding 语义检索、智能去重、完整度评分、产品增强(enrichment)。

> MVP 的"智能"至少落在:**导入时的 AI 列映射 + 报价就绪检测**——这是比"纯表格 CRUD + 上传按钮"更进一步的最小可演示智能。

## 10. 验收标准(抽样)
- 上传一个列名中英混杂的 Excel → AI 自动映射到标准字段,人工微调后入库,重复 SKU 被标记。
- 新增一个缺成本/定价规则的产品 → 标记"不可自动报价"并指出缺项。
- 智能询盘对一条非标询盘 → 能从产品库匹配到产品并返回备选 + 差异。
- 成本变更 → 智能报价侧收到受影响在途报价的预警。

## 11. 依赖
智能报价(消费成本/规格,回写"报价就绪"所需的定价规则)· 智能询盘(产品匹配/RAG/PI grounding)· 后端 `app/services/catalog*`、`product_matching`、`/api/v1/products`(含 `POST /products/import`)· 知识/embedding provider(P2)。
