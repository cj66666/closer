# 智能报价模块 · 功能需求规格(v1)

> 面向 UI 设计与开发。基于最新设计 `.claude/mockups/index.template.html` 的「智能报价」页(现为确定性规则引擎 + LLM 措辞)。本规格由产品方拍定,**重点把"智能"立住**。与「智能询盘」(消费本模块的报价能力)、「产品资料库」「智能报价」后端引擎对接。

## 1. 定位与目标

智能报价是产品的 **定价与议价大脑**:对每一条询盘,给出**该报多少、怎么让、PI 怎么出**的最优决策,既快又准又可控。

目标:报价更快(分钟级草稿)、报价采纳率↑、单均毛利↑、底价零突破、报价口径一致。

## 2. 铁律:智能负责"决策",规则负责"精确与护栏"(关键定位)

**AI 绝不凭空报数字。** 最终价格由**确定性引擎**算出(成本+物流+汇率+阶梯+毛利),底价/硬底价为**不可绕护栏**——保证精确、一致、可审计。

**"智能"体现在数字之外的判断上**:该报哪一档、推荐多少毛利、成交概率多大、怎么多轮让步、何时预警汇率侵蚀、PI 怎么得体生成、从输赢里学什么。

> 这条定位同时解决两个问题:既"智能"(会决策会议价会学习),又"可信"(价格不漂移、护栏熔断)。这是与"让 LLM 直接报价"的根本区别。

## 3. 智能内核(报价版 7 要素)

1. **智能定价建议**:对每条询盘推荐"报价点 + 毛利",依据买家等级/价格敏感度/区域/复购关系/紧迫度/竞品基准——而非一刀切 18%。
2. **成交概率与价格弹性**:预测不同价位的赢率,推荐"期望毛利 = 价格 × 赢率"最优的报价点。
3. **议价策略(护栏内)**:多轮让步阶梯——先让什么(运费险/账期/赠品/交期)再让价,识别买家还价套路。
4. **成本/汇率/物流智能感知**:自动取价并监控,标的报价毛利被汇率/运费侵蚀时**主动预警**与建议改报。
5. **报价/PI 智能生成**:grounded 在产品规格/认证/条款,多语言得体表达,与已谈定条款一致。
6. **学习与个性化**:从赢单/丢单/改价/采纳率,自动调优该卖家的阶梯建议、推荐毛利、让步偏好。
7. **可解释**:用自然语言说明"为什么建议 $172"(成本/档位/区域均价/赢率/毛利),给置信度。

## 4. 角色与范围
- 角色:报价负责人/管理员(设规则与底价、审批)、销售(看建议、发报价、议价)。
- 范围内:定价规则与护栏、智能定价建议、议价策略、成本/汇率感知、报价与 PI 生成、学习调优。
- 范围外:产品主数据(产品资料库)、会话与发送(智能询盘)、渠道(渠道接入)。本模块输出"报价能力",由智能询盘在会话中调用。

## 5. 功能需求(FR)

### FR-A 定价规则与护栏(确定性底座)
- A1 基础定价:产品成本、物流分摊(按 incoterm:FOB/CIF/DDP 自动构成 landed cost)、目标毛利率、MOQ、报价有效期、币种。
- A2 阶梯价:按数量分档,自动套档;可增删改档。
- A3 **软底价 floor_price**:任何报价/让步不得突破;触及→转人工,不自动发送。
- A4 **硬底价 hard_min_price**:后端硬熔断,即使人工审批也不可绕过(阻断报价发送与 PI 生成)。
- A5 汇率来源:实时中间价/手动;有缓存与刷新确认。
- A6 规则版本化:改动留版本,可追溯。
- A7 确定性最终数字:同输入同输出,可审计(AI 不参与最终算数)。

### FR-B 智能定价建议(per-inquiry)
- B1 对每条具体询盘**推荐报价点 + 推荐毛利**(在 A 的规则与护栏内),而非只套固定档。
- B2 推荐依据:买家等级/价格敏感度、目的国/区域均价、新客 vs 复购、数量、紧迫度、竞品基准(若有)。
- B3 给出"保守 / 推荐 / 进取"三档报价点供销售一键选。
- B4 建议永远在底价之上;低于底价只作"需审批"提示,不作可发送建议。

### FR-C 成交概率与价格弹性
- C1 对推荐的每个价位给出**赢率预测**(基于历史赢单/丢单 + 买家特征)。
- C2 给出"期望毛利最优"的推荐点(价格 × 赢率)。
- C3 弹性曲线可视化(不同价 → 赢率/期望毛利),供人工权衡。
- C4 数据不足时降级为区间经验值并标注低置信。

### FR-D 议价策略(护栏内,多轮)
- D1 让步阶梯:按"运费险 → 账期 → 赠品/增值 → 交期 → 价格"的顺序与额度给出可让清单(均在授权区间)。
- D2 读买家还价/套路(目标价、账期诉求、对比施压),给下一步策略建议(守价+给台阶)。
- D3 每一步让步都校验底价/账期红线;触红线→转人工。
- D4 让步话术 grounded(突出差异化:质保/认证/框架材料等),不止降价。

### FR-E 成本/汇率/物流智能感知(主动)
- E1 自动取汇率/运费并监控;标的有效报价毛利被侵蚀(如汇率波动)→**主动预警 + 建议改报**。
- E2 成本变更(产品资料库更新)联动提示受影响的在途报价。
- E3 有效期临近到期 → 提醒续报/跟进。

### FR-F 报价 / PI 智能生成
- F1 报价草稿:金额/阶梯/条款/有效期(数值来自引擎)+ 多语言得体表达(LLM,客户母语,保留口径)。
- F2 PI 生成 grounded 在产品规格/认证/条款,与谈定条款一致;**PI 属高风险动作,必经审批;硬底价熔断**。
- F3 文档可导出,版本留痕。

### FR-G 组合与交叉销售
- G1 一条询盘多 SKU 组合报价。
- G2 智能交叉/向上销售建议(配套件/升级款),提升单值,均在毛利与库存约束内。

### FR-H 学习与个性化(越用越准)
- H1 从赢单/丢单/人工改价/采纳率,调优该卖家的:阶梯建议、推荐毛利、让步偏好、赢率模型。
- H2 报价采纳率、议价成功率等指标回流,形成闭环。
- H3 个性化按卖家/品类/区域分层,不串租户。

### FR-I 可解释与留痕
- I1 每个报价建议附自然语言理由 + 关键数(成本/档位/毛利/赢率)+ 置信度。
- I2 报价/让步/审批/PI 全程留痕,可审计。

## 6. 报价生命周期
`AI 建议草稿` → `(在底价上)可自主发送 / (触底价)转人工审批` → `已发送` → `议价中(多轮让步)` → `PI 生成(审批)` → `成交 / 失效`

## 7. 给 UI 的视图清单
1. **规则配置**(确定性底座):基础定价、阶梯价表、软/硬底价(硬底价视觉更强,标注"不可绕过")、汇率来源、版本历史。
2. **智能报价工作台**(每条询盘):推荐报价(保守/推荐/进取三档)+ **赢率/期望毛利**展示 + 自然语言理由 + 一键采用。
3. **价格弹性视图**:价 → 赢率/期望毛利曲线。
4. **议价助手**:让步阶梯清单(可让项+额度)+ 下一步策略建议 + 红线校验提示。
5. **实时预览**(保留现有):拖数量预览引擎报价 + 底价校验。
6. **汇率/成本预警**:受影响报价列表 + 改报建议。
7. **报价/PI 文档**:多语言草稿、PI 审批态、导出、版本。
8. 空/加载/错误态。

## 8. 边界与异常
- 最终价格确定性;AI 只建议不算数。
- 硬底价后端熔断,任何路径不可绕。
- 汇率源失败 → 用缓存并标注"汇率可能过期,确认后发送"。
- 历史数据不足 → 赢率/弹性降级为经验区间 + 低置信标注,绝不假装精确。
- 报价与 PI 的条款必须与会话中已谈定一致(避免口径冲突)。

## 9. 分期(MVP / P2)
**MVP(路演必须)**:确定性规则与软/硬底价护栏(A)、智能定价建议三档 + 自然语言理由(B 简版)、议价让步阶梯建议(D 简版)、报价/PI 生成与审批(F)、实时预览、可解释与留痕。
**P2**:赢率/价格弹性预测(C)、成本/汇率主动预警(E)、组合/交叉销售(G)、学习个性化闭环(H)。

> MVP 的"智能"至少要落在:**per-inquiry 三档推荐 + 自然语言理由 + 议价让步建议**——这是与"纯计算器"拉开差距的最小可演示智能。赢率/学习作为加分项 P2。

## 10. 验收标准(抽样)
- 同一询盘 → 给出 保守/推荐/进取 三档报价,均在底价上,附自然语言理由。
- 买家目标价 < 软底价 → 不给"可发送"建议,转人工;< 硬底价 → 后端熔断。
- 汇率变动致毛利跌破阈值 → 主动预警并建议改报(P2)。
- 让步场景 → 先给非价让步(运费险/账期)再给价,均不破红线。
- 最终报价数字可由规则复算一致(确定性)。

## 11. 与产品资料库的关系(强关联)

- **链路**:询盘 → 产品匹配(命中 SKU)→ 该 SKU 的定价规则 → 智能报价建议 → 报价/PI。
- **边界**:产品库管"产品事实"(含**成本**);报价管"定价决策"(毛利/阶梯/软底价/硬底价/物流模板/有效期/汇率)。定价规则**键到 SKU**,支持"品类默认 + 单品覆盖"。
- **成本单一来源在产品库**,报价只引用不复制;产品库成本一改 → 联动预警受影响的在途报价(FR-E2)。
- **报价就绪状态**:产品同时具备 成本 + MOQ + 定价规则 才算"可自动报价";缺失 → 智能询盘不自动报价、转人工,产品库标红"待配置定价"。
- **PI/报价 grounding** 拉产品库:规格、认证、质保、交期。
- **库存/状态(在售/停产)是报价闸门**;交叉/组合销售从产品库取。
- **反向边界**:产品库不含任何价格/毛利/底价,只到"成本"为止。

## 12. 依赖
产品资料库(成本/规格/认证/库存)· 智能询盘(在会话中调用报价与议价、发送与护栏)· 后端报价引擎与底价校验(`quote_engine`、`pricing_rule.floor_price` / `logistics_template.hard_min_price`、汇率缓存、`generate_pi`)· 客户档案(复购/历史用于建议与学习)。
