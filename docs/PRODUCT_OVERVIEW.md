# 产品概述

> 跨境 B2B 中小卖家的外贸线索与客户生命周期工作台

本文从产品与商业视角说明 Closer 解决的问题、价值分层与收益模型。工程上手与架构见 [README](../README.md),技能拆解见 [skills/README](../skills/README.md),端到端证据见 [END_TO_END_EVIDENCE](END_TO_END_EVIDENCE.md)。

## 一句话定义

从多渠道线索进入 -> 信息初筛 -> 基础询盘沟通 -> 客户建档/打标 -> 意向判断 -> 跟进提醒 -> 人工接管 -> 报价准备 -> 复盘运维,AI 做低风险的识别、补全和建议,让业务员把时间集中在真实、有效、有潜在成交概率的客户上。

## 痛点切入

现状:跨境 B2B 中小卖家处理线索和询盘,常常靠销售个人经验和分散工具硬撑。

- 看邮箱、WhatsApp、独立站后台逐条处理 -> 高价值线索容易被淹没。
- 客户可能不是发完整询盘,而是只留下电话、邮箱或 Facebook Lead Ads 信息,等待卖方主动联系。
- 凭感觉判断买家诚意 -> 真实买家没有置顶,低价值询盘反而消耗销售时间。
- 翻产品表、历史报价和知识文档 -> 回复慢,需求整理和人工报价准备成本高。
- 让 AI 直接报价或承诺方案 -> 底价、交期、定制方案、合同条款都存在越权风险。
- 没有客户生命周期和跟进闭环 -> 谁该首次联系、何时跟进、何时接管都靠人工记忆。

可被验证的成本假设:

- 一个 A 级线索晚回复 12-24 小时,成交概率会明显下降。
- 一个仅留联系方式线索未及时首次联系,可能还没进入报价阶段就流失。
- 一个报价算错或底价被碰,可能直接吞掉整单毛利,因此 AI 只做报价准备,最终由业务员确认。
- 小团队每天处理几十条线索时,真正缺的不是“再来一个 AI 回复”,而是可控、可追踪、能提醒跟进的客户推进流程。

## Closer 的三层价值

### 第一层:接住真实线索

用多渠道接入、客户自动建档和信息初筛,把“谁是真买家、谁值得优先联系”先判断清楚。

- 站点表单、Email、WhatsApp、Facebook 线索进入后自动生成 customer、inquiry、conversation、message。
- 支持两类入口:完整询盘消息,以及客户只留下联系方式等待业务员主动联系。
- AI 初筛输出真实性、有效性、需求摘要、缺失信息、成交概率等级和建议下一步。
- A/B/C 分级、生命周期阶段和标签让高价值线索进入销售优先队列。

目标结果:高价值线索不漏接,销售优先级从“看谁催得急”升级为“看谁真实、有效、更可能成交”。

### 第二层:管好客户生命周期

用阶段、标签、跟进任务和接管规则,把客户从新线索推进到强意向、待报价、已报价、跟进中、成交或丢单。

- 生命周期阶段包括新线索、待首次联系、已联系、需求确认中、强意向、待人工报价、已报价、跟进中、成交/丢单。
- 客户页聚合来源、首次联系、每次沟通、标签变化、跟进提醒、人工接管和报价准备记录。
- 跟进系统围绕客户运转,自动建议 1 天、3 天、7 天等节点,逾期提醒业务员。
- 强意向、价格、方案、交期、合同和定制需求触发人工接管。

目标结果:客户推进不再靠销售记忆,老板能看到每个线索当前处于哪个阶段、下一步谁来做。

### 第三层:人工报价准备

报价能力保留,但从核心自动化降级为后置的“人工报价协同”。

- AI 可以整理产品规格、数量、目的港、证书、交期、历史价格和风险提示。
- 产品匹配、知识检索、成本、MOQ、阶梯价、汇率和底价用于准备材料,不直接对客户承诺。
- 底价、敏感承诺、大额合同、未匹配产品、PI 生成等风险动作仍必须进入人工审批。
- 报价后继续生成跟进任务和复盘记录。

目标结果:报价从“AI 直接替人报”变为“AI 帮业务员把报价前工作准备好”。

## 核心特性

- 多渠道线索直连和租户隔离,补齐 Facebook 留资线索。
- 支持完整询盘和仅留联系方式两类入口。
- AI 信息初筛、客户画像、标签、生命周期阶段和下一步建议。
- 客户跟进提醒、逾期任务、人工接管状态和客户时间线。
- 成本、MOQ、阶梯价、汇率、底价和有效期参与报价准备,不让 AI 直接承诺价格。
- React/Vite 工作台可真实操作,不是静态原型。

单店年收益估算可以按真实数据验证:

- 假设小团队每月 100 条有效线索,年有效线索 1200 条。
- 如果 AI 初筛、首次联系提醒和快速响应让成交率提升 3 个百分点,相当于每年多成交 36 单。
- 如果每单平均毛利为 ¥2000,则年增量毛利约 ¥7.2 万。
- 若客单价和毛利更高,收益主要来自三部分:少漏 A 级线索、少报错价格、少断掉跟进。

## 为什么是 Closer

Closer 的含义是“成交者”。我们的定位不是泛化客服机器人,也不是单次报价生成器,而是 **外贸线索与客户生命周期工作台**。

它把外贸销售每天最容易断裂的动作收束到一个闭环:

```text
多渠道线索
  -> 信息初筛
  -> 客户建档/打标
  -> 基础询盘沟通
  -> 生命周期阶段推进
  -> 跟进调度
  -> 人工接管
  -> 报价准备
  -> 运维就绪检查
```

核心差异是:AI 可以理解、判断和生成,但不能替业务员做高风险承诺。涉及方案设计、价格、交期、合同、定制和 PI 等动作必须人工接管并通过服务端审批护栏。
