# 使用手册 · 概述

Closer 工作台是一张 Web 界面,把外贸销售从"多渠道询盘进来"到"成交闭环"的每一步收束到一处:看板 → 询盘收件箱 → 客户档案 → 产品库/报价规则 → 报价与 PI → 审批 → 投递跟进 → 运维就绪。

## 谁在用

- **销售 / 售前**:看高优先询盘、回复、生成报价、跟进。
- **报价负责人 / 管理员**:维护产品库、价格规则(含底价护栏)、渠道凭证、审批高风险动作。

每个账号属于一个**卖家租户**,数据按租户隔离;登录后所有页面只看到本租户的数据。

## AI 与人工的边界(最重要)

AI 负责理解询盘、评分、匹配产品、起草报价和回复;但下列动作**必须人工确认**,AI 不能越权:

- 报价低于**软底价** `floor_price`
- 触碰**硬底价** `hard_min_price`(后端硬熔断,审批也不能绕过)
- 敏感承诺(账期、担保等)、大额合同条款
- 未匹配到产品的非标询盘
- PI 生成、需要销售接管的会话

这些都会进入**审批中心**留痕,确保"快"的同时"可控、可审计"。

## 最快体验:Demo Seed

在 Ubuntu 全栈 Demo 或本地启动后,点击 `Demo Seed` 一键生成演示数据(产品、价格规则、A 级询盘、报价、待审批、跟进),即可走通主链路。复现步骤见[演示手册](../DEMO_RUNBOOK.md);逐页操作见[工作台操作](./workbench.md)。
